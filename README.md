## 特徴 (Features)

本ポータルは、単なるGASアプリの枠を超えたモダンなユーザー体験とセキュリティを提供します。

* **爆速なSWR風描画機構**
  裏側で非同期に最新データをフェッチし、キャッシュを利用して画面を「0秒」で描画する SWR (Stale-While-Revalidate) パターンをGAS上で再現。ローディングのストレスを極限まで排除しています。
* **直感的なチーム共有カンバン**
  `Sortable.js` を採用し、タスクの進捗をドラッグ＆ドロップで直感的に変更可能。さらに「楽観的UI (Optimistic UI)」の導入により、サーバー通信を待たずにUIが即座に反応します。
* **DOMPurifyによる堅牢なセキュリティ**
  社内掲示板やワークフロー申請でのマークダウン入出力に対し、世界標準のHTMLサニタイザである `DOMPurify` を実装。DOM-based XSS などの脆弱性を完全にシャットアウトしています。
* **完全な多言語対応 (i18n)**
  ユーザーのGoogleアカウントの言語設定（ロケール）を自動検知し、日本語と英語のUI/エラーメッセージを動的に切り替えます。グローバルなチーム環境でもそのまま導入可能です。
* **Google Workspace フル連携**
  Gmail、Googleカレンダー、Googleドライブ、Google Cloud Searchとのシームレスな統合を実現。

## 導入方法 (Installation)

本システムは、プログラムとデータベース（スプレッドシート）を切り離す「スタンドアロン型」と、スプレッドシートに直接紐づく「コンテナバインド型」の両方に対応しています。

**推奨：スタンドアロン型**  
エンタープライズ環境での本格運用や継続的な開発を行う場合は、**スタンドアロン型**での導入を強く推奨します。
* **関心の分離**: プログラムとデータが物理的に分離されるため、誤ってスプレッドシートを削除・破損してしまっても、システム本体（ソースコード）は安全に守られます。
* **環境構築の容易さ**: 本番用・テスト用のスプレッドシートを分け、プロパティのIDを書き換えるだけで、本番環境を汚さずに安全な検証環境を構築できます。
* **バージョン管理**: `clasp` や Git を用いたローカル開発・バージョン管理がスムーズに行えます。

### パターンA：スタンドアロン型（推奨）

1. [Google Apps Script](https://script.google.com/)にアクセスし、「新しいプロジェクト」を作成します。
2. データベース用の「新規Googleスプレッドシート」を別途作成し、URLからスプレッドシートIDを控えておきます。
3. 本リポジトリの `.html` および `.gs` ファイルをプロジェクトにコピーして配置します。
4. **拡張サービスの有効化**: 左側メニューの「サービス ＋」から、以下のAPIを追加します。
   * `Admin SDK API`
   * `Google Calendar API`
   * `Google Drive API`
   * `Tasks API`
5. **スクリプトプロパティの設定**: 左側メニューの「プロジェクトの設定（歯車アイコン）」から以下を追加します。
   * `LINK_SPREADSHEET_ID` : 手順2で控えたスプレッドシートのID
   * `WORKFLOW_FOLDER_ID` : ワークフロー（電子承認・決裁）の添付ファイルを保存するGoogleドライブのフォルダID
6. **データベースの初期化**: エディタ上部の関数プルダウンから `initializeDatabaseSheets` を選択し、「実行」ボタンを押します。
   *(※初回実行時は「承認が必要です」という警告が出ます。「権限を確認」>「詳細」>「安全ではないページに移動」から許可を行ってください)*
7. **デプロイと利用開始**: 右上の「デプロイ > 新しいデプロイ」から種類を「ウェブアプリ」として公開し、発行されたURLにアクセスすればポータルの利用を開始できます。

### パターンB：コンテナバインド型

1. 新規Googleスプレッドシートを作成し、上部メニューの「拡張機能」から `Apps Script` を開きます。（※このスプレッドシートが自動的にデータベースとして認識されます）
2. 本リポジトリの `.html` および `.gs` ファイルをプロジェクトにコピーして配置します。
3. **拡張サービスの有効化**: 左側メニューの「サービス ＋」から、以下のAPIを追加します。
   * `Admin SDK API`
   * `Google Calendar API`
   * `Google Drive API`
   * `Tasks API`
4. **スクリプトプロパティの設定**: 左側メニューの「プロジェクトの設定（歯車アイコン）」から以下を追加します。（※ `LINK_SPREADSHEET_ID` の設定は不要です）
   * `WORKFLOW_FOLDER_ID` : ワークフロー（電子承認・決裁）の添付ファイルを保存するGoogleドライブのフォルダID
5. **データベースの初期化**: エディタ上部の関数プルダウンから `initializeDatabaseSheets` を選択し、「実行」ボタンを押します。
   *(※初回実行時は「承認が必要です」という警告が出ます。「権限を確認」>「詳細」>「安全ではないページに移動」から許可を行ってください)*
6. **デプロイと利用開始**: 右上の「デプロイ > 新しいデプロイ」から種類を「ウェブアプリ」として公開し、発行されたURLにアクセスすればポータルの利用を開始できます。

## 機能仕様

### **1. ポータルダッシュボード＆ウィジェットカスタマイズ機能**

#### **機能説明**

ユーザーごとの業務スタイルや好みに合わせてメイン画面を自在にアレンジできるダッシュボード機能です。ポータル画面上に配置される各種ウィジェット（Gmail最新トレイ、Google Driveエクスプローラ［最近のファイル/マイドライブ/共有ドライブの階層ブラウジング対応］、カレンダー、社内掲示板、承認・確認待ちタスク、BCP防災情報、リンク集など）の並び順や幅（25%、50%、75%、100%）をドラッグ＆ドロップで簡単にカスタマイズできます。

#### **利用方法**

* **ヘッダー領域**: 「Google Workspaceポータル」タイトル、Cloud Search検索窓（有効時）、履歴・申請・カレンダー・カンバン画面へのワンクリック遷移ボタン、およびワッフルメニュー（アプリランチャー）アイコンが配置されています。  
* **ポータルグリッド**: 設定されたウィジェットがレスポンシブに配置されます。各ウィジェットの右上には「再読み込み（更新）」ボタンと各サービスの本体画面を開く外部リンクボタンが配置されています。  
* **個人設定画面**: ワッフルメニューの「個人設定」からアクセスできます。  
  * 「テーマカラー」: カラーパレットからお好みのカラー（デフォルトは\#1abc9c）を選択可能です。  
  * 「ウィジェットの配置」: 各項目のドラッグハンドルをつかんで上下に並び替えられます。幅選択プルダウン（25%/50%/75%/100%）でレイアウトを変更でき、「新しい掲示板ブロックを追加」ボタンで最大5つまで掲示板を追加可能です。  
  * 「ワッフルメニューのリンク設定」: チェックボックスのオン/オフでメニュー表示を切替、ドラッグで順序変更が可能です。「独自リンクを追加」ボタンで個人専用のURL・表示名・アイコンを追加できます。  
  * 「保存してポータルに戻る」ボタンを押すことで設定が反映されます。

#### **ユーザーが準備すべきこと**

特段不要（Google Workspaceアカウントでポータルにアクセスするだけで直ちに利用可能です）。

### **2. Google Cloud Search 横断検索連携機能**

#### **機能説明**

ポータルのヘッダー領域に組み込まれた社内横断検索機能です。Google Workspaceの検索サービスである「Google Cloud Search」と直接連携し、ポータルからワンクリックでGoogle Drive内のドキュメント、Gmail、Google Calendar、Google Chatなど、社内の全Workspaceコンテンツを一括で横断検索できます。PC画面だけでなく、モバイル画面にも最適化された検索Modal UIを備えています。

#### **利用方法**

* **PC利用時**: ヘッダー中央の「Cloud Searchで検索...」入力窓にキーワードを入力し、Enterキーを押すことで別タブにてGoogle Cloud Searchの検索結果画面が開きます。  
* **モバイル利用時**: ヘッダーの虫眼鏡アイコンをタップして検索モーダルを起動し、キーワードを入力してEnterキーを押すことで検索を実行できます。

#### **ユーザーが準備すべきこと**

Google Cloud Searchが利用可能なGoogle Workspaceライセンス（Business Plus, Enterprise等）を契約・保持していること。また、管理者によって「マスタ管理」画面でCloud Search連携が有効化されている必要があります。

### **3. 社内掲示板（Googleグループ連携）機能**

#### **機能説明**

所属しているGoogleグループ（メーリングリスト）宛ての投稿やスレッドをポータル上に自動取得・一覧表示する掲示板機能です。Markdown形式に対応したリッチテキストエディタ（EasyMDE）を内蔵しており、ポータル画面上から直接新規投稿を行ったり、過去のスレッドに対して返信（全員へ返信 / 投稿者へ個別返信）を送信することができます。インライン画像表示や添付ファイル（合計最大20MB）の表示・直接ダウンロードにも対応しており、社内の情報共有や連絡事項の確認をポータル内で完結させることができます。

#### **利用方法**

* **掲示板ウィジェット**: 選択されたGoogleグループの最新投稿がスレッド形式で表示されます。返信件数バッジが表示され、「投稿」ボタンで新規投稿モーダル、「グループ本体を開く」ボタンでGoogle Groupsへ直接アクセスできます。  
* **新規投稿モーダル**: 「件名」テキスト入力欄、「本文」Markdownエディタ、「添付ファイル」選択ボタン（PCからファイル追加、合計最大20MB）に入力し、「投稿する」ボタンを押下することでグループ全員へ一括送信されます。  
* **掲示板詳細・返信モーダル**: 掲示板一覧のスレッドをクリックして起動します。メッセージ履歴、差出人、送信日時、HTML本文、添付ファイル（クリックでダウンロードまたは別タブ表示）が確認できます。「全員に返信」「投稿者に返信」ボタンでモードを切り替え、返信本文と添付ファイルを入力して「送信する」ボタンで返信します。

#### **ユーザーが準備すべきこと**

投稿および閲覧を行いたいGoogleグループ（メーリングリスト）にユーザーのアカウントがメンバーとして登録されていること。また、個人設定画面にて表示対象のグループを選択しておく必要があります。

### **4. ワークフロー（電子承認・決裁）機能**

#### **機能説明**

社内の稟議・各種申請・承認業務を完全に電子化する高機能なワークフローシステムです。個人用および所属組織グループ用の多段承認・供覧ルートテンプレートを作成・管理できます。起票時にはMarkdownによる詳細本文の記述、ローカルPCからのファイル添付（合計20MBまで）、および容量無制限のGoogleドライブからのファイル選択・自動複製添付が可能です。ステップごとの承認者はワンクリックで承認・供覧確認・却下・差戻しを行え、処理コメントとともに履歴が記録されます。さらに、完了済みチケットを検索・参照できるマイチケット（申請履歴）機能や、データベースの自動/手動アーカイブ機構も備えています。

#### **利用方法**

* **承認・確認待ちタスクウィジェット**: 自分宛ての承認待ち（赤バッジ）/供覧待ち（青バッジ）タスクが一覧表示されます。  
* **新規申請モーダル** (ヘッダーの「申請する」ボタンから起動):  
  * ステップ1: 件名、詳細内容（Markdownエディタ）、PCファイル追加、Googleドライブピッカー（マイドライブ/共有ドライブ/最近のファイルから複数選択）を設定し「次へ」を押下します。  
  * ステップ2: 申請ルート（既存テンプレート選択または新規作成）、各ステップの処理種別（承認/供覧）と担当者（個人/グループ）を設定します。「この経路設定を新しいテンプレートとして保存する」にチェックを入れるとテンプレートマスタへ保存できます。「申請する」ボタンで起票されます。  
* **承認・確認モーダル**: ウィジェット内のタスクをクリックして起動します。申請内容・添付ファイルを確認し、コメント入力欄に理由や申し送り事項を入力の上、「承認する」「確認しました」「却下」「差戻し」ボタンで処理を実行します。  
* **申請履歴（マイチケット）モーダル**: ヘッダーの「履歴」ボタンから起動します。「現在の申請」タブで進行中のチケット検索、「過去ログを検索」タブで完了・アーカイブ済みチケットを件名や日付範囲指定で検索・詳細閲覧できます。  
* **マイルート設定モーダル** (個人設定画面内から起動): ルートの追加・削除、ルート名・公開範囲（個人/組織グループ）・有効/無効・文書保持期間（期間指定/日付指定/永久保存）の設定、ステップの追加・削除・ドラッグ並び替えを行い、「ルートを保存する」ボタンで保存します。

#### **ユーザーが準備すべきこと**

* **管理者側の準備**: 添付ファイルを保存するためのGoogleドライブ上の格納フォルダーを作成し、そのフォルダーIDをGASのスクリプトプロパティ `WORKFLOW_FOLDER_ID` に設定しておくこと。  
* **一般ユーザー側の準備**: 頻繁に利用する申請経路がある場合は、あらかじめ「マイルート設定」画面で申請テンプレートを作成しておくこと。

### **5. チーム共有カンバンボード＆Google Tasksハイブリッド同期機能**

#### **機能説明**

チームおよび個人のタスクを「未着手」「進行中」「確認中」「完了」の4つのレーンで可視化・管理できるカンバンボード機能です。ドラッグ＆ドロップによる直感的なステータス変更（Optimistic UI対応）をはじめ、優先度（高/中/低）、期限設定、所属グループやマイタスクごとの表示切り替えが可能です。さらに、タスクの担当者に自分自身を指定した場合、個人の「Google Tasks (ToDoリスト)」と双方向で自動連携され、どちらから完了にしても相互のステータスがリアルタイムに同期されます。

#### **利用方法**

* **カンバン画面** (ヘッダーの「カンバン」アイコンから起動):  
  * グループ切り替えプルダウンで「マイタスク」または「所属グループ」を選択して表示対象を切り替えます。  
  * タスクカードを目的のレーン（未着手/進行中/確認中/完了）へドラッグ＆ドロップしてステータスを更新します。  
  * カードホバー時の「編集」アイコンで編集モーダルを起動します。  
* **タスク作成・編集モーダル**: 「タスク追加」ボタンまたは編集アイコンから起動します。表示先（ボート/スコープ）、タスク名、優先度（高/中/低）、期限（日付指定）、担当者（マイタスクでは自分固定、グループタスクではグループメンバーから選択）を入力し、「追加する」または「更新する」ボタンを押下します。「タスクを削除」ボタンでタスクを完全削除できます。

#### **ユーザーが準備すべきこと**

特段不要（Google Tasksとの連携はアカウント認証により自動で行われます。グループでタスクを共有・担当割り当てしたい場合は、対象のGoogleグループに参加している必要があります）。

### **6. グループカレンダー＆会議室（リソース）空き状況検索機能**

#### **機能説明**

マイカレンダーおよび所属グループメンバーのスケジュールをタイムライン形式で横断表示できるグループカレンダー機能です。1日表示・3日表示の切り替え、日付指定ジャンプ、今日へのワンクリック移動に対応しています。また、ドメイン内の会議室（リソース）一覧の検索や、指定した日時（開始〜終了時刻）に空いている会議室をGoogle Calendar FreeBusy APIを用いて一括空室検索し、カレンダータイムライン上に会議室の予定を並べて表示・比較する高度な設備予約支援機能を備えています。

#### **利用方法**

* **グループカレンダー画面** (ヘッダーの「カレンダー」アイコンから起動):  
  * 上部操作バーで「1日」「3日」表示切替、「今日」ボタン、日付選択ピッカー、表示グループ選択プルダウンを設定します。  
  * 「予定を作成」ボタンでGoogleカレンダーの予定作成画面を別タブで起動できます。  
  * タイムラインエリアにメンバーごとの予定ブロックが表示されます（ホバーで予定のタイトル・時間帯をポップアップ表示）。  
* **会議室を探す（スライドパネル）**: 画面右上の建物アイコンボタンでパネルを開閉します。  
  * テキスト検索窓で会議室名や定員をキーワード検索できます。  
  * 「指定時間で空いている部屋を探す」領域で、日付、開始時刻、終了時刻を入力し「空室検索」ボタンを押下すると、その時間帯に空いている会議室のみをフィルタリング表示します。  
  * 会議室カードの「＋追加」ボタンを押すと、メインのタイムライン上にその会議室の予約状況行が追加表示されます。

#### **ユーザーが準備すべきこと**

* **管理者側の準備**: Google Workspace管理コンソール（またはAdmin SDK）にて、社内の会議室や備品が「ビルディング/リソース」として適切に登録されていること。  
* **一般ユーザー側の準備**: 他のメンバーの予定を閲覧するために、相互にGoogleカレンダーの参照権限（「予定の時間枠のみ指定」または「すべての予定の詳細の閲覧」）が許可されていること。

### **7. BCP（防災・運行情報・全社アラート）機能**

#### **機能説明**

緊急時や災害時の迅速な状況把握と社員の安全確保を支援するBCP（事業継続計画）機能です。気象庁APIと連携し、ユーザーが設定した「自宅エリア」および「勤務先エリア」の最新気象情報・注意報・警報テキストをリアルタイム表示します。また、ワンクリックで該当地域のYahoo\!雨雲レーダー（動的座標マッピング）を起動できるほか、主要な鉄道（JR・私鉄・新幹線）や航空会社の運行情報リンク集（個人専用の独自路線リンク追加対応）を提供します。さらに、管理者が発信した全社緊急メッセージはポータル画面最上部に目立つ赤帯アラートとして即座に表示されます。

#### **利用方法**

* **緊急アラートバー**: 管理者が緊急メッセージを設定している場合、ポータル最上部に赤背景・警告アイコン付きでメッセージが表示されます。  
* **BCPウィジェット**:  
  * 「運行情報リンク」: 設定された鉄道会社・航空会社等のボタンをクリックして運行情報ページを別タブで表示します。  
  * 「自宅・勤務先エリアの天気」: 自宅・勤務先の気象情報を閲覧できます。レーダーアイコンをクリックすると該当地域のYahoo\!雨雲レーダーを直接開きます。  
  * 「気象庁: 警報・注意報の詳細を見る」リンクから気象庁の防災情報サイトへアクセスできます。  
* **個人設定画面**: 「防災・運行情報の設定」セクションで、自宅エリア（47都道府県・地域）と勤務先エリアを選択し、表示したい運行情報リンクの選択・独自路線URLの追加が可能です。

#### **ユーザーが準備すべきこと**

個人設定画面にて、自身の「自宅エリアの天気」および「勤務先エリアの天気」を設定しておくこと。

### **8. ポータル管理者機能（マスタ管理・システム最適化）**

#### **機能説明**

ポータルサイト全体の管理・運用を行うシステム管理者専用の機能です。全社共通で表示する「静的リンクマスタ」の追加・編集・削除・ドラッグ並び替え、Google Cloud Search検索窓の有効/無効切替、全社向け「緊急メッセージ（BCPアラート）」の作成・更新、およびシステムパフォーマンス維持のための「自動データベース最適化（アーカイブ）」のスケジュール設定・手動バッチ実行が行えます。アーカイブ実行時には、完了済みのカンバンタスクや決裁完了チケットを過去ログ用シートへ自動退避し、バッチ実行中の数分間はメンテナンス画面を表示してデータ保護を行います。

#### **利用方法**

* **マスタ管理画面** (管理者ユーザーがワッフルメニューの「マスタ管理」から遷移):  
  * **Google Cloud Search 連携**: トグルスイッチでポータルヘッダーへの検索窓表示/非表示を切り替えます。  
  * **緊急メッセージ発信**: テキストエリア（Markdown対応）に全社アラートを入力し、「緊急メッセージを更新」ボタンで発信します（空欄にして更新すると解除）。  
  * **自動データベース最適化 (アーカイブ)**: トグルスイッチで自動バッチを有効化します。実行曜日、時刻、ワークフロー退避基準（30日/90日/180日/365日経過）を設定します。「手動で今すぐ実行」ボタンで即時アーカイブバッチを実行可能です。  
  * **リンクマスタ管理**: 「新しいリンクを追加」ボタンで追加モーダルを起動し、表示名・URL・アイコンを選択します。ドラッグ＆ドロップで並び替え後、「マスタを保存してポータルに戻る」ボタンで保存します。

#### **ユーザーが準備すべきこと**

データベース用スプレッドシートの `AdminList` シートのA列に、管理者権限を付与するユーザーのメールアドレスを追加登録しておくこと（ヘッダー行は不要です）。また、スタンドアロン型で導入した場合は、GASのスクリプトプロパティ `LINK_SPREADSHEET_ID` が正しく設定されている必要があります。

### **9. グローバル・多言語対応 (i18n) 機能**

#### **機能説明**

海外拠点や多様な国籍のメンバーが在籍するグローバルなチーム環境でもそのまま導入できるよう、システム全体が多言語（日本語・英語）に完全対応しています。ブラウザやGoogleアカウントの言語設定（ロケール）をシステムが自動検知し、ユーザーごとに最適な言語でUIを表示します。

#### **利用方法**

* **動的UI切り替え**: 画面上のメニュー、ボタン、説明文などのフロントエンドテキストが、アクセスしたユーザーの言語設定に合わせて自動で切り替わります（現在、日本語 `ja` と英語 `en` に対応）。
* **バックエンドエラーのローカライズ**: システムの裏側（GASサーバー側）で発生したアクセス権限エラーや入力不備のアラートメッセージも、実行ユーザーの言語に合わせて翻訳されて画面にフィードバックされます。

#### **ユーザーが準備すべきこと**

特段不要（ユーザーのGoogle Workspaceアカウントの言語設定が自動的に適用されます）。
